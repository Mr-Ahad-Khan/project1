# 🛒 Blinkit Clone

A modern and responsive **Blinkit-inspired grocery e-commerce website** built with **React**, **Tailwind CSS**, and **JavaScript**. The application features a clean UI, product listings, hero banner, search bar, shopping cart, and a mobile-friendly layout that delivers a seamless shopping experience.

---

## ✨ Features

- 🛍️ Responsive E-commerce UI
- 🔍 Product Search Bar
- 🏠 Hero Banner Section
- 🛒 Shopping Cart
- 📦 Product Cards
- ⚡ Fast & Responsive Design
- 🎨 Modern UI with Tailwind CSS

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Mr-Ahad-Khan/Blinkit-Clone.git
```

### Navigate to the Project

```bash
cd Blinkit-Clone
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
